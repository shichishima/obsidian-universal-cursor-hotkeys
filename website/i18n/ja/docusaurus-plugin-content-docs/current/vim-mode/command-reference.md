# Vim mode — コマンドリファレンス

各トグルが何をON/OFFするかは[設定](/vim-mode/settings)を参照してください。このページでは各キーが実際に何をするかを説明します。

## モーションのアップグレード

Vim自身のネイティブキーに対する修正で、Live Previewのテーブルセル内に限定されます — テーブルの外では、これらはすべてバニラのVimと変わりません。

| キー | 機能概要 |
| :--: | ----------------- |
| `h` `l` `x` | テーブルセル内でも文字単位の移動・削除を正しく行います — マルチバイト文字の数え間違いや、行境界での誤ったジャンプがありません。 |
| `j` `k` | 次/前のテーブル行に列位置（vim自身の目標列）を保ったまま移動します。セルの境界で止まってしまうことがなく、複数行にまたがる（折り返された）セル内でも正しい行に止まります。 |
| `w` `b` `e`（および `W`/`B`/`E`/`ge`/`gE`） | セル・行の境界をまたいで移動します — テーブルの末尾に達すると、周囲のテキストへ抜け出し、vim自身のドキュメント全体にわたる単語移動の挙動と一致します（テーブルの端で止まってしまうことがありません）。CJK対応（辞書ベースの中国語・日本語の単語分割）で、バニラvimのようなスクリプト境界のみの判定ではありません。 |
| `gg` `G` | 常にノートの実際の最初/最後の行に到達し、テーブルセルから完全に抜け出すことも含みます。その行がテーブルの行だった場合はSmart Home対応の本文位置に着地します。ノートがテーブルで終わっている場合、`G`は空行を追加してそこに着地します（テーブルの中に着地することはありません。下記の`tx`のEOF挙動と同様です）— `gg`には対称的な「行を先頭に追加する」ケースはありません。 |
| `gj` `gk` | 上記の`j`/`k`の表示行版です — テーブルセル内で止まってしまうことなく表示行単位で移動し、折り返された行をまたいでも表示上の列位置を追跡します。 |
| `$` | `j`/`k`や`gj`/`gk`が続くときの行末への吸着（sticky）目標列で、テーブル行をまたぐ場合も含め、実際のvimの挙動と一致します。`D`/`C`も同じ基盤となるモーションを共有します。 |
| `^` `I` | vimの素の「空白文字のみをスキップ」ではなく、Smart home自身の本文開始位置の判定ロジックを再利用します。どこまでスキップするかは動作オプションの設定によります: **Smart home (standard)** はリスト・チェックボックスのマーカー、インデント、引用マーカーをスキップします。**Smart home (advanced)** はさらに見出し・脚注・コールアウトの種類マーカーもスキップします。 |
| `J` | vimの素の「空白文字のみの結合」ではなく、Smart join自身の行結合ロジックを再利用します（vim通常通り、結合時にスペースを1つ挿入する点は変わりません）。動作オプションの**Smart join**設定に依存します: ONの場合、単なる空白ではなく次の行のMarkdown記法（引用・リストマーカー、インデント）を取り除きます。 |

## Table structure

新しいリーダーキーコマンド（`<leader>`はデフォルトで`Space`、`\`も選択可）です — 既存のvimキーの修正ではなく、Obsidian組み込みのテーブルコマンドへの薄いラッパーです。`tm`を除き、テーブルセルの外では何もしません。`tiJ`/`tiK`は`to`/`tO`のエイリアスで、`tiH`/`tiL`自身の「`ti` + 方向」という列挿入の命名規則に合わせています。

| | 行 | 列 |
| --- | --- | --- |
| 挿入 | `<leader>to` / `<leader>tO`<br/>`<leader>tiJ` / `<leader>tiK`<br/>（下/上） | `<leader>tiH` / `<leader>tiL`<br/>（左/右） |
| 移動 | `<leader>tK` / `<leader>tJ`<br/>（上/下） | `<leader>tH` / `<leader>tL`<br/>（左/右） |
| 削除 | `<leader>tdd` | `<leader>tdc` |
| 複製 | `<leader>tyyp` | `<leader>tyc` |
| 揃え | — | `<leader>tal` / `<leader>tac` / `<leader>tar`<br/>（左/中央/右） |

`<leader>tm` — テーブルを挿入します。ここに挙げたコマンドの中で唯一、既存のテーブルの外でも動作します。

## Table navigation

新しいリーダーキーコマンドです — 純粋なカーソル移動で、既存の何かへのラッパーではない独自ロジックです。テーブルセルの外では何もしません。

| キー | 機能概要 |
| :--: | ----------------- |
| `<leader>tj` / `<leader>tk` | 下/上のセル（同じ列）へジャンプし、その本文の先頭に着地します — vimネイティブの`j`/`k`が本文の先頭ではなく列位置を保つのとは異なります。 |
| `<leader>th` / `<leader>tl` | 左/右のセルへジャンプし、その本文の先頭に着地します — 選択範囲は作られません。Obsidian組み込みの`Tab`/`Shift-Tab`によるセル移動（行の左右端で次/前の行に回り込み、テーブルが尽きると新しい行を挿入し、移動先セルの内容全体を選択する）とは異なり、`th`/`tl`は常に現在の行の中にとどまり、行の左右端では何もしません。 |
| `<leader>tx` / `<leader>tX` | 現在のテーブルから下/上に抜け出します — ドキュメント全体の端にジャンプする`gg`/`G`とは異なり、このテーブルだけを通り過ぎます。 |
