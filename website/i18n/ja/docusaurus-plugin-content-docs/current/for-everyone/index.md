# For everyone

このプラグインの恩恵を受けるのに、Vimモードやmacos風キーバインドは必要ありません。普段から使っている矢印キー・Home・End・Page Up/Down・単語移動が、キーの役割を変えることなく、テーブル対応・CJK対応（中国語・日本語の単語分割）になります。

**設定 → Universal Cursor Hotkeys → For everyone** を開いて **Apply all** をクリックしてください。

関連: [コマンドリファレンス](/for-everyone/command-reference)、[設定](/for-everyone/settings)、[動作オプション](/behavior-options)。
