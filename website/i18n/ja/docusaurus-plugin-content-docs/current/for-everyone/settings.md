# For everyone — 設定

Obsidianの **設定** → コミュニティプラグイン **Universal Cursor Hotkeys** を選択 → 上部タブ **For everyone** を開きます。

## Apply all ボタン
このページにあるすべての設定トグルをONにします。(Upgrade navigation basics × 8つ、Upgrade word commands × 4つ、Behavior options × 5つ)

ただし、競合可能性があるもの(🔴Used ステータス)はスキップされます。

## Upgrade navigation basics (基本操作のアップグレード)
各キー設定は単純なON/OFFトグルです。各キー設定の挙動変化の詳細は [キーのアップグレード(基本操作のアップグレード)](/for-everyone/key-upgrades#upgrade-navigation-basics) を参照してください。

ONにするとそのキーが対象コマンドのホットキーに追加されます。すでに対象コマンドにホットキーが割り当てられている場合は、それらはそのままに、このキーが追加登録されます。

OFFにするとそのキーの割り当てだけが削除されます。他のホットキー割り当ては変化しません。

### 各設定行の見方 \{#setting-status}

| ステータス      | トグル              | 意味                                                                                                                                                            |
| ---------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| (表示なし)     | OFF              | キーは標準挙動そのままで変更されていません。アップグレード挙動が割り当て可能な状態です。                                                                                                                  |
| (表示なし)     | ON               | キーがこのプラグインのアップグレード挙動に割り当てられています。                                                                                                                              |
| 🔴Used     | OFF<br/>(disable) | このキーはすでに別のコマンドで使用されています。このため、このコマンドを追加で割り当てることができません。(ONにすることはできません)<br/>キーチップあるいはステータスをクリックするとObsidianのホットキー設定画面に遷移するので、そこで割り当て中のコマンドを確認してください。               |
| 🔴Conflict | ON               | アップグレードコマンドがこのキー自体とそれ以外のコマンドの両方に割り当てられていて、現状すでに競合状態です。<br/>キーチップあるいはステータスをクリックしてホットキー設定画面に移動し、競合状態を整理してください。なおトグルスイッチをOFFにすると 🔴Used ステータスに変化し、そのままではONにできません。 |

## Behavior options (挙動オプション)  \{#behavior-options}
各種挙動を調整するトグルボタンです。

同じ名称の設定項目は「For everyone」「Vim mode」「macOS (Emacs) style」で連動していて、一方でON(またはOFF)にすると他方でも連動してON(またはOFF)になります。

| 設定                         | デフォルト | 説明                                                                                                                                                                                                                                          |
| -------------------------- | :---: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Smart&nbsp;home (standard) |  ON   | **ON:** `Home` キーが先頭のMarkdown記法(リスト、番号付きリスト、チェックボックス、インデント、引用)の手前、本文テキストの先頭に移動します。Windowsの `Home` / macOSの `command` + ← と同様の挙動です。<br/><br/>**OFF:** `Home` キーはMarkdown記法を考慮せず、行の先頭に直接移動します。macOS / Emacsの `Ctrl` + `A` と同様の挙動です。             |
| Smart&nbsp;home (advanced) |  ON   | **ON:** Smart home (standard)の挙動に加えて、見出し(`#`)、脚注(`[^1]:`)、コールアウトの種類マーカー(`[!type]`)も追加で考慮します。Smart home (standard) がONの場合のみONにできます。<br/><br/>**OFF:** 見出し行・脚注・コールアウトを考慮しません。(素の `Home` と同等に論理行頭に移動します)                                         |
| Visual line movement       |  ON   | **ON:** 折り返しのある長い行で `Home` / `End` を押した際、1段階目は表示行の先頭/末尾に移動します。<br/><br/>**OFF:** 折り返し行であっても `Home` / `End` は表示行を考慮しません。`Home` は行の先頭(Smart home設定により、論理行の先頭または本文テキストの先頭)、`End` は論理行の末尾に移動します。                                                  |
| Cross-row navigation       |  ON   | テーブル内での `Home` / `End` の挙動を調整します。<br/><br/>**ON:** 左端セルの先頭で `Home` を押すと、上の行の右端セル末尾に移動します。同様に、右端セル末尾で `End` を押すと下の行の左端セル先頭に移動します。<br/>行がない場合にはテーブルの外に脱出します。<br/>(← / → の挙動相当です)<br/><br/>**OFF:** `Home` / `End` でテーブル行移動せず、左端セル先頭または右端セル末尾で停止します。 |
| Double-click word select   |  ON   | マウスのダブルクリックによる単語選択の挙動を調整します。<br/><br/>**ON:** 辞書ベース単語分割により、マウスダブルクリック時に日本語の単語単位で範囲選択します。<br/>ダブルクリック後にドラッグすると、単語単位で選択範囲が拡張します。<br/><br/>**OFF:** Obsidian標準のダブルクリック挙動です。日本語は漢字ひらがなを区別せずひとまとまりで選択されます。                                            |
