# For everyone — 制限事項

- **Key Upgrades を適用したキーは他のプラグインのビューで動作しなくなる場合があります**
	- 例えば Excalidraw では、↑ / ↓ をアップグレードするとオブジェクトの上下移動やテキスト編集中のカーソル上下移動ができなくなります。`Home` / `End` をアップグレードするとテキスト編集中の `Home` / `End` が効かなくなり、`Page Up` / `Page Down` をアップグレードするとキャンバスのパン(スクロール)ができなくなります。
	- 支障がある場合には対象キーの Key Upgrades をオフにしてください。
