# For everyone — 制限事項

- **Key Upgrades を適用したキーはノート本文エディタ以外で動作しなくなる場合があります**
	- 以下にいくつかの例を挙げますが、これに限るものではありません。
		- ↑ / ↓ をアップグレードするとフロントマターの項目移動に ↑ / ↓ が使えなくなります。
		- `Home` / `End` をアップグレードするとノートタイトルで `Home` / `End` が使えなくなります。
		- Bases においては、↑ / ↓ のアップグレードでリスト表示での項目移動、`Page Up` / `Page Down` のアップグレードでリスト表示/カード表示ともに画面スクロールが効かなくなります。
		- Excalidraw では、↑ / ↓ をアップグレードするとオブジェクトの上下移動やテキスト編集中のカーソル上下移動ができなくなります。`Home` / `End` をアップグレードするとテキスト編集中の `Home` / `End` が効かなくなり、`Page Up` / `Page Down` をアップグレードするとキャンバスのパン(スクロール)ができなくなります。
	- 支障がある場合には対象キーの Key Upgrades をオフにしてください。
