# macOS (Emacs) style — コマンドリファレンス

各コマンドの詳しい挙動は[コマンド詳細](/macos-emacs-style/command-details)を参照してください。グループ分けは下記のHotkey settingsと同じです。

## Cursor movement

| コマンド名 | 推奨<br/>ホットキー | 機能概要 | キー<br/>リピート |
| :--------: | :----------------: | ---------------- | :---: |
| UP    | Ctrl + P           | Smart UP: テキスト/セル間の移動、テーブル・コールアウトへの進入（下から）・退出（上から）。 | ✓ |
| DOWN  | Ctrl + N           | Smart DOWN: テキスト/セル間の移動、テーブル・コールアウトへの進入（上から）・退出（下から）。 | ✓ |
| LEFT  | Ctrl + B           | Smart LEFT: 文字単位の移動、または前のセルへのジャンプ。 | ✓ |
| RIGHT | Ctrl + F           | Smart RIGHT: 文字単位の移動、または次のセルへのジャンプ。 | ✓ |
| HOME  | Ctrl + A           | Smart HOME: 表示行の端、本文の先頭、行の先頭の順に段階的に移動します。テーブル内では前のセルへジャンプします。 | ✓ |
| END   | Ctrl + E           | Smart END: 表示行の端、または行末の順に段階的に移動します。テーブル内では次のセルへジャンプします。 | ✓ |
| TOP | —          | ドキュメントの最初の位置へジャンプします。テーブル対応。 |  |
| BOTTOM | —        | ドキュメントの最後の位置へジャンプします。テーブル対応。 |  |
| Page up | —        | 1ページ分上にスクロールします。カーソルは画面上の同じ位置にとどまります。素のPageUpキーはプラグインの設定から割り当てられます。 | ✓ |
| Page down | —        | 1ページ分下にスクロールします。カーソルは画面上の同じ位置にとどまります。素のPageDownキーはプラグインの設定から割り当てられます。 | ✓ |
| Word right | —        | 単語単位で前方へ移動します。テーブル対応、CJK対応。 | ✓ |
| Word left | —         | 単語単位で後方へ移動します。テーブル対応、CJK対応。 | ✓ |

## Editing

| コマンド名 | 推奨<br/>ホットキー | 機能概要 | キー<br/>リピート |
| :--------: | :----------------: | ---------------- | :---: |
| Kill line | Ctrl + K      | カーソルから行末までをKillします。連続してKillするとキルキャッシュとクリップボードに蓄積されます。 | ✓ |
| Kill region | Ctrl + W    | 選択範囲をキルキャッシュに切り取ります。テーブル対応: 単一セルのみ対応、複数行または複数セルにまたがる選択では何もしません。 |  |
| Copy region | —     | 選択範囲を削除せずにキルキャッシュへコピーします。Kill regionと同じテーブル対応の制約があります。 |  |
| Yank | Ctrl + Y           | OSのクリップボードから貼り付けます。テーブル対応: 改行とパイプ文字を自動的に変換します。 | ✓ |
| Delete char | Ctrl + D   | 1文字を前方削除します。セルの境界で止まり、Live Preview内では`<br/>`をまたいでサブ行を結合します。 | ✓ |
| Undo | Ctrl + /   | 直前の変更を元に戻します。 | ✓ |
| Redo | —      | 直前に元に戻した変更をやり直します。 | ✓ |
| Kill word left | — | カーソルから前の単語の先頭までをKillします。テーブル対応: 現在のセル内にとどまり、セルの端では何もしません。 | ✓ |
| Kill word right | — | カーソルから次の単語の末尾までをKillします。テーブル対応: 現在のセル内にとどまり、セルの端では何もしません。 | ✓ |
| Uppercase word | — | 選択範囲、または選択がなければカーソル位置の単語全体を大文字にします。テーブル対応、CJK対応。 | ✓ |
| Lowercase word | — | 選択範囲、または選択がなければカーソル位置の単語全体を小文字にします。テーブル対応、CJK対応。 | ✓ |
| Capitalize word | — | 選択範囲（単語ごと）、または選択がなければカーソル位置の単語全体の先頭を大文字にします。テーブル対応、CJK対応。 | ✓ |
| Transpose chars | — | カーソル前後の2文字を入れ替えます。行やセルの末尾では、代わりに直前の2文字を入れ替えます。テーブル対応、Unicodeセーフ。 | ✓ |
| Select all | —         | Ctrl+AがHOMEに再割り当てされた場合の、Windows向けSelect allの代替コマンドです。 |  |

## Other hotkeys

| コマンド名 | 推奨<br/>ホットキー | 機能概要 | キー<br/>リピート |
| :--------: | :----------------: | ---------------- | :---: |
| Recenter-top-bottom | Ctrl + L | 押すたびに、カーソルが画面の中央・上端・下端のいずれかに来るように表示位置を切り替えます。他の操作を行うとリセットされます。 |  |
| Recenter | —         | カーソルのある行が画面中央になるようにスクロールします。 |  |

## Table structure

このプラグイン自身が持つコマンドではなく、Obsidian組み込みのテーブル編集コマンドです。下記のHotkey settingsと同様にここにも掲載し、見つけてホットキーを割り当てやすくしています。

| コマンド名 | 推奨<br/>ホットキー | 機能概要 |
| :--------: | :----------------: | ---------------- |
| Insert row above | — | 現在の行の上に新しい行を挿入します。 |
| Insert row below | — | 現在の行の下に新しい行を挿入します。 |
| Move row up | — | 現在の行を上に移動します。 |
| Move row down | — | 現在の行を下に移動します。 |
| Duplicate row | — | 現在の行を複製します。 |
| Delete row | — | 現在の行を削除します。 |
| Insert column left | — | 現在の列の左に新しい列を挿入します。 |
| Insert column right | — | 現在の列の右に新しい列を挿入します。 |
| Move column left | — | 現在の列を左に移動します。 |
| Move column right | — | 現在の列を右に移動します。 |
| Align column left | — | 現在の列を左揃えにします。 |
| Align column center | — | 現在の列を中央揃えにします。 |
| Align column right | — | 現在の列を右揃えにします。 |
| Duplicate column | — | 現在の列を複製します。 |
| Delete column | — | 現在の列を削除します。 |
| Insert table | — | カーソル位置に新しいテーブルを挿入します — ここに挙げたコマンドの中で唯一、既存のテーブルの外でも動作します。 |

## Table navigation

6つの通常コマンドで、**設定 → Hotkeys** またはHotkey settingsから割り当てられます。テーブルセルの外では何もしません。

| コマンド名 | 推奨<br/>ホットキー | 機能概要 | キー<br/>リピート |
| :--------: | :----------------: | ---------------- | :---: |
| Move to cell left | — | 左隣のセルへジャンプし、その本文の先頭に着地します — 選択範囲は作られません。Obsidian組み込みの`Tab`/`Shift-Tab`によるセル移動（行の左右端で次/前の行に回り込み、テーブルが尽きると新しい行を挿入し、移動先セルの内容全体を選択する）とは異なります。 | ✓ |
| Move to cell right | — | 右隣のセルへジャンプし、その本文の先頭に着地します — 選択範囲は作られません。Move to cell leftと同様に`Tab`/`Shift-Tab`とは異なります。 | ✓ |
| Move to cell below | — | 下の行の同じ列にあるセルへ直接ジャンプし、その本文の先頭に着地します。 | ✓ |
| Move to cell above | — | 上の行の同じ列にあるセルへ直接ジャンプし、その本文の先頭に着地します。 | ✓ |
| Exit table below | — | テーブルから下の行へ抜け出します — ドキュメント全体の末尾にジャンプするCursor BOTTOMとは異なり、このテーブルだけを通り過ぎます。 | ✓ |
| Exit table above | — | テーブルから上の行へ抜け出します — ドキュメント全体の先頭にジャンプするCursor TOPとは異なり、このテーブルだけを通り過ぎます。 | ✓ |
