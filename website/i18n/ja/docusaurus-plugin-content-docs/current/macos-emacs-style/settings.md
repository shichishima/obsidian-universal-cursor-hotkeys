# macOS (Emacs) style — 設定
Obsidianの **設定** → コミュニティプラグイン **Universal Cursor Hotkeys** を選択 → 上部タブ **macOS (Emacs) style** を開きます。

設定画面は大きく「[Hotkey settings (ホットキー設定)](/macos-emacs-style/settings#hotkey-settings)」と「[Behavior options (挙動オプション)](/macos-emacs-style/settings#behavior-options)」で構成されています。

通常、プラグインのホットキー割り当てはObsidian標準のホットキー設定画面で行いますが、このプラグインではプラグイン設定画面の中でホットキー割り当て状態の確認と推奨設定の一括割り当てが行えます。

## Hotkey settings (ホットキー設定) \{#hotkey-settings}
ここには5つのコマンドグループ(→[解説](/macos-emacs-style/settings#command-groups))と「Displaced commands」(→[解説](/macos-emacs-style/settings#displaced-commands))の計6つのブロックがあります。

### Apply recommended ボタン \{#apply-recommended}
コマンドグループ Cursor movement / Editing / Other hotkeys の見出しの右側に3つの **Apply recommended** ボタンがあります。これを押すとそのコマンドグループの推奨ホットキーを一括で割り当てます。

インストール直後の Obsidian であればそのまま3つの **Apply recommended** を押して構いません。macOSでは初期状態でのホットキー競合はありません。Windowsでは推奨ホットキーと重なる既定のホットキー(`Ctrl` + `P` のコマンドパレットなど)が Displaced commands に送られますが、これらはすべて **Restore** で元に戻せます。(→[Displaced commands 解説](/macos-emacs-style/settings#displaced-commands))

すでにホットキーを自分でカスタマイズしている場合は、他のホットキーが残るコマンド(🔵Used など)から外れたホットキーは Displaced commands に載らず **Restore** で戻せません。気になる場合は押す前に各行の Status を確認してください。(→[Status 解説](/macos-emacs-style/settings#status))

一括割り当ての対象は、そのコマンドグループのうちホットキーがまだ1つも割り当てられていないコマンドです(→[例外あり](/macos-emacs-style/settings#status-exception))。すでに割り当てられているコマンド(✅Set、🟢Custom)と、推奨ホットキーがないコマンド(—)には影響しません。

推奨ホットキーを別のコマンドが使用中の場合(🔵Used、🟡Used、推奨ホットキーが別の複数のコマンドに割り当てられている 🔴Conflict)は、それらのコマンドから推奨ホットキーを外して、代わりにこちらのコマンドに推奨ホットキーを割り当てます。ホットキーが1つも残らなくなったコマンドはDisplaced commandsに送られます。

### 画面の見方
各コマンドグループは次の項目を持つ表になっています。

| 項目                     | 説明                                                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Command**            | このプラグインが提供するコマンド名です。Obsidian標準のホットキー設定画面で表示される名称です。                                                                                        |
| **Recommended Hotkey** | Emacs風の最低限の推奨ホットキーです。<br/>**Apply recommended** で割り当てる内容を示します。                                                                              |
| **Current Hotkey**     | 現在割り当てられているホットキーです。複数ある場合には一部省略表示されることがあります。すべて表示する場合にはキーチップをクリックしてください。                                                                   |
| **Status**             | このコマンドのホットキー割り当て状態を示します。([後述](/macos-emacs-style/settings#status))                                                                         |
| **▶Individual**        | 個々のコマンドを細かく調整するためのアクションボタンを表示します。([後述](/macos-emacs-style/settings#individual))<br/>**▶Individual** をクリックしてこの列に調整用のボタンを表示させてください。(デフォルト非表示) |

コマンド名またはキーチップをクリックすると、そのコマンド名またはキーで絞り込んだ状態でObsidian標準のホットキー設定画面に遷移します。

<Anchor id="status-exception" />

**例外：** UP、DOWN、HOME、END の4つのコマンドでは「For everyone」が割り当てる素のキー(↑、↓、`Home`、`End`)を Status の判定で割り当てとして数えません。素のキーだけが割り当てられている場合も推奨ホットキーが未割り当ての状態として扱い、**Set** / **Override** ボタンが出ます。

**理由：** これらのコマンドは「UP は ↑ と `Ctrl` + `P`」「HOME は `Home` と `Ctrl` + `A`」のように、素のキーと推奨ホットキーの両方を割り当てて使うことを想定しています。もし素のキーを割り当てとして数えると「For everyone」を先にONにした場合にこれらのコマンドが「割り当て済み(🟢Custom)」と判定され、こちら側の **Apply recommended** や **Set** / **Override** が適用できず、推奨ホットキーの追加割り当てができなくなってしまうためです。

### Individual ボタン一覧 \{#individual}
ホットキーの割り当て状況に応じて、割り当ての実行または状況確認を行うための次の3種類のボタンが表示されます。

| Individual ボタン | 説明                                                                                                                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Set**        | 推奨ホットキーが空いている状態です。<br/>**Set** ボタンを押すと推奨ホットキーが割り当てられます。                                                                                                                                    |
| **Override**   | 現在、推奨ホットキーは別のコマンドに割り当てられています。使用中のコマンド名がインラインで表示されます。<br/>**Override** ボタンを押すと、使用中のコマンドから推奨ホットキーを外して、このコマンドに割り当てます。<br/>ホットキーが1つも残らなくなったコマンドは Displaced commands に送られます。(🟡Used は必ずこれにあたります) |
| **Open →**     | コマンド名で絞り込んだ状態でObsidian標準のホットキー設定画面に遷移します。                                                                                                                                                 |

### Displaced commands (退避されたコマンド) \{#displaced-commands}
推奨ホットキーの適用によって、割り当てられていた唯一のホットキーを失ったコマンドの一覧です。各項目にはObsidian標準のホットキー設定画面から再割り当てするための **Assign** ボタンと、推奨ホットキーの割り当てを取り消して元のコマンドにキーを戻す **Restore** ボタンがあります。

| 項目                 | 説明                                                                                                                                                                                                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Command**        | 推奨ホットキーの適用によりホットキーを失ったコマンドの名前です。クリックするとコマンド名で絞り込んだ Obsidian標準のホットキー設定画面が開きます。                                                                                                                                                                                        |
| **Assign<br/>ボタン**  | 上と同じくホットキー設定画面を開きます。新しいホットキーを割り当て直すために使います。                                                                                                                                                                                                                          |
| **Hotkey**         | 推奨ホットキーの適用により失われたホットキーです。クリックするとキーで絞り込んだ Obsidian標準のホットキー設定画面が開きます。                                                                                                                                                                                                  |
| **Displaced by**   | Command 欄のコマンドが「Displaced commands」に送られた理由となった、このプラグインのコマンド名です。クリックするとコマンド名で絞り込んだ Obsidian標準のホットキー設定画面が開きます。<br/>元々「Command のコマンド → Hotkey キー」だったところを、<br/>「Displaced by のコマンド → Hotkey キー」<br/>「Command のコマンド → 割り当て解除」<br/>のように Displaced by のコマンドが Hotkey を奪い取った格好です。 |
| **Restore<br/>ボタン** | 現状「Displaced by のコマンド → Hotkey キー」ですが、これを<br/>「Command のコマンド → Hotkey キー」<br/>「Displaced by のコマンド → 割り当て解除」<br/>として、Hotkey が奪われる前の元の状態に戻します。                                                                                                                            |

この **Restore** ボタンにより、**Apply recommended** による一括割り当ての後でも比較的安全に元のホットキー状態を復元できます。

**Assign** ボタンや **Restore** ボタン、あるいは標準のホットキー設定画面によって Command 欄のコマンドにホットキーが割り当てられると、この表からは消えます。「なにかしらのホットキーによって当該コマンドが起動できるならば問題ない」という考え方によるもので、「ホットキーを割り当てて表から消すべき」という意味ではありません。

マウス操作で実行可能であったり、利用頻度が低ければコマンドパレットからの実行で十分であるものについては Displaced commands に残ったままにしておいても良いでしょう。

## Behavior options (挙動オプション) \{#behavior-options}
各種挙動を調整するトグルボタンです。

同じ名称の設定項目は「For everyone」「Vim mode」「macOS (Emacs) style」で連動していて、一方でON(またはOFF)にすると他方でも連動してON(またはOFF)になります。

| 設定                         | デフォルト | 説明                                                                                                                                                                                                                                                                                    |
| -------------------------- | :---: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Smart&nbsp;home (standard) |  ON   | **ON:** HOMEコマンドが先頭のMarkdown記法(リスト、番号付きリスト、チェックボックス、インデント、引用)の手前、本文テキストの先頭に移動します。Windowsの `Home` / macOSの `command` + ← と同様の挙動です。<br/><br/>**OFF:** HOMEコマンドはMarkdown記法を考慮せず、行の先頭に直接移動します。macOS / Emacsの `Ctrl` + `A` と同様の挙動です。                                                         |
| Smart&nbsp;home (advanced) |  ON   | **ON:** Smart home (standard)の挙動に加えて、見出し(`#`)、脚注(`[^1]:`)、コールアウトの種類マーカー(`[!type]`)も追加で考慮します。Smart home (standard) がONの場合のみONにできます。<br/><br/>**OFF:** 見出し行・脚注・コールアウトを考慮しません。(素の `Home` と同等に動作します)                                                                                        |
| Smart join                 |  OFF  | **ON:** Kill line コマンドによる行の結合において、次の行の先頭のMarkdownを削除します。<br/>Smart home (standard) がONである必要があります。<br/>引用マーカー・リストマーカー・インデントを削除するほか、Smart home (advanced) がONの場合には見出しや脚注も削除します。<br/><br/>**OFF:** 次の行をそのまま結合します。                                                                            |
| Visual line movement       |  ON   | **ON:** 折り返しのある長い行で HOME / END を実行した際、1段階目は表示行の先頭/末尾に移動します。<br/><br/>**OFF:** 折り返し行であっても HOME / END は表示行を考慮しません。HOME は行の先頭(Smart home設定により、論理行の先頭または本文テキストの先頭)、END は論理行の末尾に移動します。                                                                                                       |
| Cross-row navigation       |  ON   | テーブル内での LEFT / RIGHT / HOME / END の挙動を調整します。<br/><br/>**ON:** 左端セルの先頭で LEFT / HOME を実行すると、上の行の右端セル末尾に移動します。同様に、右端セル末尾で RIGHT / END を実行すると下の行の左端セル先頭に移動します。<br/>行がない場合にはテーブルの外に脱出します。<br/>(素のキー ← / → の挙動相当です)<br/><br/>**OFF:** LEFT / RIGHT / HOME / END でテーブル行移動せず、左端セル先頭または右端セル末尾で停止します。 |
