
推奨ホットキーの適用によって、割り当てられていた唯一のホットキーを失ったコマンドの一覧です。各項目には Obsidian 標準のホットキー設定画面から再割り当てするための **Assign** ボタンと、推奨ホットキーの割り当てを取り消して元のコマンドにキーを戻す **Restore** ボタンがあります。

| 項目                 | 説明                                                                                                                                                                                                                                                                    |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Command**        | 推奨ホットキーの適用によりホットキーを失ったコマンドの名前です。クリックするとコマンド名で絞り込んだ Obsidian 標準のホットキー設定画面が開きます。                                                                                                                                                                                        |
| **Assign<br/>ボタン**  | 上と同じくホットキー設定画面を開きます。新しいホットキーを割り当て直すために使います。                                                                                                                                                                                                                           |
| **Hotkey**         | 推奨ホットキーの適用により失われたホットキーです。クリックするとキーで絞り込んだ Obsidian 標準のホットキー設定画面が開きます。                                                                                                                                                                                                  |
| **Displaced by**   | Command 欄のコマンドが「Displaced commands」に送られた理由となった、このプラグインのコマンド名です。クリックするとコマンド名で絞り込んだ Obsidian 標準のホットキー設定画面が開きます。<br/>元々「Command のコマンド → Hotkey キー」だったところを、<br/>「Displaced by のコマンド → Hotkey キー」<br/>「Command のコマンド → 割り当て解除」<br/>のように Displaced by のコマンドが Hotkey を奪い取った格好です。 |
| **Restore<br/>ボタン** | 現状「Displaced by のコマンド → Hotkey キー」ですが、これを<br/>「Command のコマンド → Hotkey キー」<br/>「Displaced by のコマンド → 割り当て解除」<br/>として、Hotkey が奪われる前の元の状態に戻します。                                                                                                                             |

この **Restore** ボタンにより、**Apply recommended** による一括割り当ての後でも比較的安全に元のホットキー状態を復元できます。

**Assign** ボタンや **Restore** ボタン、あるいは標準のホットキー設定画面によって Command 欄のコマンドにホットキーが割り当てられると、この表からは消えます。「なにかしらのホットキーによって当該コマンドが起動できるならば問題ない」という考え方によるもので、「ホットキーを割り当てて表から消すべき」という意味ではありません。
マウス操作で実行可能であったり、利用頻度が低ければコマンドパレットからの実行で十分であるものについては Displaced commands に残ったままにしておいても良いでしょう。
