各コマンドグループは次の項目を持つ表になっています。

| 項目                     | 説明                                                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Command**            | このプラグインが提供するコマンド名です。Obsidian 標準のホットキー設定画面で表示される名称です。                                                                                       |
| **Recommended Hotkey** | Emacs 風の最低限の推奨ホットキーです。<br/>**Apply recommended** で割り当てる内容を示します。                                                                             |
| **Current Hotkey**     | 現在割り当てられているホットキーです。複数ある場合には一部省略表示されることがあります。すべて表示する場合にはキーチップをクリックしてください。                                                                   |
| **Status**             | このコマンドのホットキー割り当て状態を示します。([後述](/macos-emacs-style/settings#status))                                                                         |
| **▶Individual**        | 個々のコマンドを細かく調整するためのアクションボタンを表示します。([後述](/macos-emacs-style/settings#individual))<br/>**▶Individual** をクリックしてこの列に調整用のボタンを表示させてください。(デフォルト非表示) |

コマンド名またはキーチップをクリックすると、そのコマンド名またはキーで絞り込んだ状態で Obsidian 標準のホットキー設定画面に遷移します。
