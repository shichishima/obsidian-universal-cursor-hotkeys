# For everyone — 限制事项

- **应用了按键升级的按键，可能无法在笔记正文编辑器以外的地方使用**
  - 以下列举几个示例，但并不仅限于此。
    - 升级 ↑/↓ 后，将无法再使用 ↑/↓ 在属性中切换项目。
    - 升级 `Home`/`End` 后，将无法再在笔记标题中使用 `Home`/`End`。
    - 在 Bases 中，升级 ↑/↓ 后将无法在列表视图中切换项目；升级 `Page Up`/`Page Down` 后，列表视图和卡片视图都无法再滚动屏幕。
    - 在 Excalidraw 中，升级 ↑/↓ 后将无法上下移动对象，也无法在编辑文本时上下移动光标。升级 `Home`/`End` 后，编辑文本时的 `Home`/`End` 将失效；升级 `Page Up`/`Page Down` 后，将无法对画布进行平移（滚动）。
  - 如果因此造成不便，请关闭该按键对应的按键升级开关。
