# For everyone — 命令参考

本页是按照 [设置页面](/for-everyone/settings) 的命令分组列出的命令一览与功能概述。各命令的详细行为请参阅 [命令详情](/command-details)。

- 命令名称栏显示的是 Obsidian 标准快捷键设置页面中显示的名称。
  - 各个命令名称都链接到 **命令详情** 页面中的相应命令。
- 推荐快捷键栏是通过 **[Apply recommended](/for-everyone/settings#apply-recommended)** 按钮或 **Set** 按钮分配的按键。
  - 在 Windows 上，部分快捷键与 Obsidian 自身的标准快捷键重叠。分配后，请在 [Displaced commands](/for-everyone/settings#displaced-commands) 栏确认原本分配给该快捷键的命令状态。
  - 在 macOS 上，请将其替换为 `control` 键。
  - "—" 表示尚未设置推荐快捷键。请点击 **Open →** 按钮，打开 Obsidian 标准快捷键设置页面，手动分配你想要的快捷键。
- 按键重复栏显示 "✓" 的命令表示支持按键重复。

## Add cursor（添加光标） \{#add-cursor}

这 2 个命令是为了避免 Obsidian 标准「在上方添加光标」「在下方添加光标」命令的不稳定行为而重新实现的。

| 命令名称 | 推荐<br/>快捷键<br/>（macOS） | 推荐<br/>快捷键<br/>（Windows） | 功能概述 | 按键<br/>重复 |
| :---: | :---: | :---: | --- | :---: |
| [Add cursor above](/command-details#add-cursor-above-below) | `option` + ↑ | `Alt` + ↑ | 在当前光标的上一行添加一个光标。 | ✓ |
| [Add cursor below](/command-details#add-cursor-above-below) | `option` + ↓ | `Alt` + ↓ | 在当前光标的下一行添加一个光标。 | ✓ |
