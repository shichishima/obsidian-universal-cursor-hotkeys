# For everyone — 按键升级

本页说明启用本插件后，各个按键的行为会发生怎样的变化。

行为升级的实质，是将插件命令分配给快捷键。由于部分按键无法在 Obsidian 的快捷键设置页面中设置，因此需要使用本插件设置页面中的开关。快捷键的分配状态确认与取消分配，同样可以在快捷键设置页面中进行。

## 基础操作升级 \{#upgrade-navigation-basics}
如需查看详情，请点击对应命令列中的链接。

|            键<br/>（macOS）            |      键<br/>（Windows）      | 对应命令                                                         | 行为概述                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| :---------------------------------: | :-----------------------: | -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|                  ↑                  |             ↑             | [UP](/macos-emacs-style/command-details#cursor-up)             | **支持表格**<br/>跨越表格行移动时，现在会保持光标的水平位置（列字符位置）。<br/>此前跨越表格行时，光标总是会移动到行首。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|                  ↓                  |             ↓             | [DOWN](/macos-emacs-style/command-details#cursor-down)         | **支持表格**<br/>与 ↑ 相同，跨越表格行时会保持光标位置。<br/>此前跨越行时，光标总是会移动到行首。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|   `Home`<br/>（`fn`&nbsp;+&nbsp;←）    |          `Home`           | [HOME](/macos-emacs-style/command-details#cursor-home)         | **Smart home**<br/>光标将按照显示行左端 → （跳过行首 Markdown 标记后的）正文文本开头 → 行首的顺序移动。<br/>这与标准的 `Home` 键行为相同，但开启 [Smart home (advanced)](/for-everyone/settings#behavior-options) 后，原本不会执行该行为的标题行（`#`）、脚注行（`[^1]:`）、标注（`> [!type]`），也会在第 2 步移动到正文文本开头。<br/>关闭 [Smart home (standard)](/for-everyone/settings#behavior-options) 后将不再考虑行首的 Markdown 标记，关闭 [Visual line movement](/for-everyone/settings#behavior-options) 后将不再移动到显示行左端。<br/><br/>**支持表格**<br/>在表格中，于单元格开头按下 `Home` 会移动到左侧单元格的末尾。<br/>此前会停留在单元格开头。<br/><br/>此外，当 [Cross-row navigation](/for-everyone/settings#behavior-options) 开启时，会从最左侧单元格开头移动到上一行最右侧单元格的末尾；关闭时则停留在最左侧单元格开头。 |
|    `End`<br/>（`fn`&nbsp;+&nbsp;→）    |           `End`           | [END](/macos-emacs-style/command-details#cursor-end)           | **支持表格**<br/>在单元格末尾按下 `End` 会移动到右侧单元格的开头。<br/>此前会停留在单元格末尾。<br/><br/>此外，当 [Cross-row navigation](/for-everyone/settings#behavior-options) 开启时，会从最右侧单元格末尾移动到下一行最左侧单元格的开头；关闭时则停留在最右侧单元格末尾。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|       `command`&nbsp;+&nbsp;↑       | `Ctrl`&nbsp;+&nbsp;`Home` | [TOP](/macos-emacs-style/command-details#cursor-top-bottom)    | **支持表格**<br/>将光标移动到笔记开头。若笔记开头是表格，则会移动到表头行的开头。<br/>此前若开头是表格，会移动到表格的最后一行。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|            `command` + ↓            |      `Ctrl` + `End`       | [BOTTOM](/macos-emacs-style/command-details#cursor-top-bottom) | **支持表格**<br/>将光标移动到笔记末尾。若笔记末尾是表格，则会移动到最底部一行的末尾。<br/>此前若笔记末尾是表格，会移动到表头行的开头。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|  `Page Up`<br/>（`fn`&nbsp;+&nbsp;↑）  |         `Page Up`         | [Page up](/macos-emacs-style/command-details#page-up-down)     | **支持表格**<br/>滚动页面时，光标会保持在屏幕上的同一位置，即使滚动后的位置落在表格内部，也能正确落位。<br/>此前即便本应落在表格内部，光标也一定会移动到表格外。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `Page Down`<br/>（`fn`&nbsp;+&nbsp;↓） |        `Page Down`        | [Page down](/macos-emacs-style/command-details#page-up-down)   | **支持表格**<br/>与 `Page Up` 相同。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## 单词操作升级 \{#upgrade-word-commands}
如需查看详情，请点击对应命令列中的链接。

|                            键<br/>（macOS）                            |        键<br/>（Windows）         | 对应命令                                                                     | 功能概述                                                                                                                                                                       |
| :-----------------------------------------------------------------: | :----------------------------: | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|                       `option`&nbsp;+&nbsp;→                        |      `Ctrl`&nbsp;+&nbsp;→      | [Word right](/macos-emacs-style/command-details#word-left-right)           | **支持中文**<br/>按中文/英文单词为单位向右移动。（中文基于词典进行分词）<br/>此前，连续的汉字会被视为一个不可分割的单词整体。                                                                              |
|                       `option`&nbsp;+&nbsp;←                        |      `Ctrl`&nbsp;+&nbsp;←      | [Word left](/macos-emacs-style/command-details#word-left-right)            | **支持中文**<br/>按中文/英文单词为单位向左移动。                                                                                                                                          |
|                       `option`&nbsp;+&nbsp;⌫                        | `Ctrl`&nbsp;+&nbsp;`Backspace` | [Kill word left](/macos-emacs-style/command-details#kill-word-left-right)  | **支持中文**<br/>按中文/英文单词为单位删除左侧的单词，并存入剪贴板。连续删除的内容会作为一整段文本存入剪贴板。（Emacs 风格的行为：可以将连续删除的多个单词通过一次粘贴整体贴回）<br/>此前无法识别中文分词，且删除内容也不会存入剪贴板。 |
| `option`&nbsp;+&nbsp;⌦<br/>（`option`&nbsp;+&nbsp;`fn`&nbsp;+&nbsp;⌫） |  `Ctrl`&nbsp;+&nbsp;`Delete`   | [Kill word right](/macos-emacs-style/command-details#kill-word-left-right) | **支持中文**<br/>同样会按单词为单位删除右侧的单词，并存入剪贴板。                                                                                                                               |
