# For everyone — Command Reference

Commands and function summaries, grouped the same way as on the [Settings](/for-everyone/settings) page. For detailed behavior of each command, see [Command Details](/command-details).

- The Command Name column shows the name as it appears on Obsidian's own Hotkeys panel.
  - Each command name links to that command's entry on the Command Details page.
- The Recommended Hotkey column shows the key assigned by the **[Apply recommended](/for-everyone/settings#apply-recommended)** button or the **Set** button.
  - On Windows, some of these overlap with Obsidian's own standard hotkeys. After applying, check the [Displaced commands](/for-everyone/settings#displaced-commands) list to see what happened to the command that previously held that hotkey.
  - On macOS, read `Ctrl` as `control`.
  - "—" means no recommended hotkey is set. Click the **Open →** button to open Obsidian's own Hotkeys panel and assign a hotkey of your choice manually.
- Commands with "✓" in the Key Repeat column support key repeat.

## Add cursor \{#add-cursor}

These 2 commands are reimplemented to avoid the unstable behavior of Obsidian's standard "Add cursor above"/"Add cursor below" commands.

| Command Name | Recommended<br/>Hotkey<br/>(macOS) | Recommended<br/>Hotkey<br/>(Windows) | Function Summary | Key<br/>Repeat |
| :---: | :---: | :---: | --- | :---: |
| [Add cursor above](/command-details#add-cursor-above-below) | `option` + ↑ | `Alt` + ↑ | Adds a multi-cursor on the line above the current cursor. | ✓ |
| [Add cursor below](/command-details#add-cursor-above-below) | `option` + ↓ | `Alt` + ↓ | Adds a multi-cursor on the line below the current cursor. | ✓ |
