# For everyone — Key Upgrades

This page explains how each key's behavior changes once you apply this plugin.

A behavior upgrade is, in reality, just a plugin command assigned to a hotkey. Some keys can't be configured from Obsidian's own Hotkeys panel, so you need to use this plugin's own Settings screen toggles instead. You can still check what's assigned, and remove an assignment, from the Hotkeys panel.

## Navigation basics upgrade \{#upgrade-navigation-basics}

| :---------------------------------: | :-----------------------: | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|                  ↑                  |             ↑             | [UP](/macos-emacs-style/command-details#cursor-up)             | **Table-aware**<br/>Preserves the horizontal cursor position (the column's character position) when crossing a table row.<br/>Previously, crossing a table row always moved the cursor to the start of the line.                                                                                                                                                                                                                                                                                                                                                                                                 |
|                  ↓                  |             ↓             | [DOWN](/macos-emacs-style/command-details#cursor-down)         | **Table-aware**<br/>Same as ↑ above — preserves the cursor position when crossing a table row.<br/>Previously, crossing a row always moved the cursor to the start of the line.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|   `Home`<br/>(`fn`&nbsp;+&nbsp;←)    |          `Home`           | [HOME](/macos-emacs-style/command-details#cursor-home)         | **Smart home**<br/>Moves the cursor in this order: the current visual line's left edge → the content start (skipping any leading Markdown syntax) → the line start.<br/>This matches the standard `Home` key's own behavior, but turning on [Smart home (advanced)](/for-everyone/settings#behavior-options) extends step 2 to also reach the content start on heading lines (`#`), footnote lines (`[^1]:`), and callouts (`> [!type]`) — previously, step 2 left these lines untouched.<br/>Turning [Smart home (standard)](/for-everyone/settings#behavior-options) OFF disables the leading-Markdown skip entirely, and turning [Visual line movement](/for-everyone/settings#behavior-options) OFF disables the visual-line-edge step.<br/><br/>**Table-aware**<br/>Inside a table, pressing `Home` at the start of a cell moves to the end of the cell to the left.<br/>Previously, it stayed at the cell start.<br/><br/>Also, with [Cross-row navigation](/for-everyone/settings#behavior-options) ON, pressing it at the leftmost cell's start moves to the end of the rightmost cell in the row above. With it OFF, it stays at the leftmost cell's start. |
|    `End`<br/>(`fn`&nbsp;+&nbsp;→)    |           `End`           | [END](/macos-emacs-style/command-details#cursor-end)           | **Table-aware**<br/>Inside a table, pressing `End` at the end of a cell moves to the start of the cell to the right.<br/>Previously, it stayed at the cell end.<br/><br/>Also, with [Cross-row navigation](/for-everyone/settings#behavior-options) ON, pressing it at the rightmost cell's end moves to the start of the leftmost cell in the row below. With it OFF, it stays at the rightmost cell's end.                                                                                                                                                                                                      |
|       `command`&nbsp;+&nbsp;↑       | `Ctrl`&nbsp;+&nbsp;`Home` | [TOP](/macos-emacs-style/command-details#cursor-top-bottom)    | **Table-aware**<br/>Moves the cursor to the start of the note. If the note starts with a table, moves to the start of the header row.<br/>Previously, when the note started with a table, it moved to the table's last row instead.                                                                                                                                                                                                                                                                                                                                                                              |
|            `command` + ↓            |      `Ctrl` + `End`       | [BOTTOM](/macos-emacs-style/command-details#cursor-top-bottom) | **Table-aware**<br/>Moves the cursor to the end of the note. If the note ends with a table, moves to the end of its bottom row.<br/>Previously, when the note ended with a table, it moved to the start of the header row instead.                                                                                                                                                                                                                                                                                                                                                                                |
|  `Page Up`<br/>(`fn`&nbsp;+&nbsp;↑)  |         `Page Up`         | [Page up](/macos-emacs-style/command-details#page-up-down)     | **Table-aware**<br/>Scrolls the page while keeping the cursor at the same position on screen. Lands correctly even when the scrolled-to position falls inside a table.<br/>Previously, even when the cursor should have landed inside a table, it was always pushed out past the table instead.                                                                                                                                                                                                                                                                                                                 |
| `Page Down`<br/>(`fn`&nbsp;+&nbsp;↓) |        `Page Down`        | [Page down](/macos-emacs-style/command-details#page-up-down)   | **Table-aware**<br/>Same as `Page Up` above.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## Word commands upgrade \{#upgrade-word-commands}
Click the applied command to see the full details.

|                            Key<br/>(macOS)                            |        Key<br/>(Windows)         | Applied Command                                                                 | Function Summary                                                                                                                                                                                                             |
| :-----------------------------------------------------------------: | :----------------------------: | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|                       `option`&nbsp;+&nbsp;←                        |      `Ctrl`&nbsp;+&nbsp;←      | [Word left](/macos-emacs-style/command-details#word-left-right)             | **CJK-aware**<br/>Moves left by word, for Chinese/Japanese and English text alike (Chinese/Japanese word boundaries come from dictionary-based word segmentation).<br/>Previously, a run of Chinese/Japanese characters was treated as a single unbroken word.          |
|                       `option`&nbsp;+&nbsp;→                        |      `Ctrl`&nbsp;+&nbsp;→      | [Word right](/macos-emacs-style/command-details#word-left-right)            | **CJK-aware**<br/>Likewise moves right by word.                                                                                                                                             |
|                       `option`&nbsp;+&nbsp;⌫                        | `Ctrl`&nbsp;+&nbsp;`Backspace` | [Kill word left](/macos-emacs-style/command-details#kill-word-left-right)   | **CJK-aware**<br/>Deletes the word to the left, for Chinese/Japanese and English text alike, and stores it on the clipboard. Consecutive deletions accumulate into one continuous run of text on the clipboard (Emacs-style behavior — a chain of consecutive word deletions can then be pasted back in a single paste).<br/>Previously, Chinese/Japanese word boundaries weren't recognized at all, and nothing was stored on the clipboard either. |
| `option`&nbsp;+&nbsp;⌦<br/>(`option`&nbsp;+&nbsp;`fn`&nbsp;+&nbsp;⌫) |  `Ctrl`&nbsp;+&nbsp;`Delete`   | [Kill word right](/macos-emacs-style/command-details#kill-word-left-right)  | **CJK-aware**<br/>Likewise deletes the word to the right and stores it on the clipboard.                                                                                                                         |
