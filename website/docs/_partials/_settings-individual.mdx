ホットキーの割り当て状況に応じて、割り当ての実行または状況確認を行うための次の 3 種類のボタンが表示されます。

| Individual ボタン | 説明                                                                                                                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Set**        | 推奨ホットキーが空いている状態です。<br/>**Set** ボタンを押すと推奨ホットキーが割り当てられます。                                                                                                                                    |
| **Override**   | 現在、推奨ホットキーは別のコマンドに割り当てられています。使用中のコマンド名がインラインで表示されます。<br/>**Override** ボタンを押すと、使用中のコマンドから推奨ホットキーを外して、このコマンドに割り当てます。<br/>ホットキーが 1 つも残らなくなったコマンドは Displaced commands に送られます。(🟡Used は必ずこれにあたります) |
| **Open →**     | コマンド名で絞り込んだ状態で Obsidian 標準のホットキー設定画面に遷移します。                                                                                                                                                 |
