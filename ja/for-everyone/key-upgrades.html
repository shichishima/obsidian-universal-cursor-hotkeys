For everyone — キーのアップグレード

このページでは各キーの挙動がプラグイン適用によってどう変わるのかを説明します。

挙動アップグレードの実態はホットキーへのプラグインコマンドの割り当てです。一部のキーは Obsidian のホットキー設定画面では設定することができないため、このプラグイン設定画面のトグルスイッチを使用する必要があります。ホットキー割り当て状況の確認と割り当て解除はホットキー設定画面からも行えます。

基本操作のアップグレード​

詳細を確認するには適用コマンドの欄をクリックしてください。

キー
(macOS)		キー
(Windows)		適用コマンド挙動概要
↑↑UPテーブル対応
テーブルの行をまたいで移動した際に横方向のカーソル位置 (カラム文字位置) を維持するようになります。
これまではテーブルの行をまたぐとカーソルは必ず行頭に移動していました。
↓↓DOWNテーブル対応
↑ と同様に、テーブル行またぎの際にカーソル位置を維持します。
これまでは行またぎの際に必ず行頭に移動していました。
Home
(fn + ←)		HomeHOMESmart home
表示行の左端 → (行頭の Markdown 記法をスキップした) 本文テキストの先頭 → 行の先頭、という順でカーソルを移動させます。
これは標準の Home キーと同じ挙動ですが、「Smart home (advanced)」を ON にすることで、これまでこの挙動をしていなかった見出し行 (#)、脚注行 ([^1]:)、コールアウト (> [!type]) でも 2 ステップ目で本文テキストの先頭に移動するようになります。
Smart home (standard) を OFF にすると行頭のマークダウン考慮をしなくなり、Visual line movement を OFF にすると表示行の左端移動をしなくなります。

テーブル対応
テーブルにおいては、セル先頭で Home を押すと左のセルの末尾に移動します。
これまではセル先頭にとどまっていました。

また、Cross-row navigation が ON の場合は左端セルの先頭から上の行の右端セルの末尾に移動します。OFF の場合は左端セル先頭にとどまります。
End
(fn + →)		EndENDテーブル対応
セル末尾で End を押すと右のセルの先頭に移動します。
これまではセル末尾にとどまっていました。

また、Cross-row navigation が ON の場合、右端セルの末尾から下の行の左端セルの先頭に移動します。OFF の場合は右端セル末尾にとどまります。
command + ↑Ctrl + HomeTOPテーブル対応
ノート先頭にカーソル移動します。ノートの先頭がテーブルの場合、見出し行の先頭にカーソル移動します。
これまでは、先頭がテーブルの場合にはテーブルの最終行に移動していました。
command + ↓Ctrl + EndBOTTOMテーブル対応
ノート末尾にカーソル移動します。ノートの末尾がテーブルの場合、最下段の末尾にカーソル移動します。
これまでは、ノート末尾がテーブルの場合は見出し行の先頭にカーソル移動していました。
Page Up
(fn + ↑)		Page UpPage upテーブル対応
画面上の同じ位置にカーソルを保ったままページをスクロールします。スクロール位置がテーブルの中であっても適切に着地します。
これまでは、本来ならテーブルの内部に着地するような場合でも必ずテーブルの外までカーソル移動していました。
Page Down
(fn + ↓)		Page DownPage downテーブル対応
Page Up と同様です。

単語操作のアップグレード​

詳細を確認するには適用コマンドの欄をクリックしてください。

キー
(macOS)		キー
(Windows)		適用コマンド機能概要
option + ←Ctrl + ←Word left日本語対応
日本語 / 英語の単語単位で左に移動します。(日本語は辞書ベースの単語分割による)
これまでは連続する漢字ひらがな等はひとかたまりの単語とみなされていました。
option + →Ctrl + →Word right日本語対応
同様に単語単位で右に移動します。
option + ⌫Ctrl + BackspaceKill word left日本語対応
日本語 / 英語の単語単位で左の単語を削除し、クリップボードに格納します。連続した削除は一連のテキストとしてクリップボードに格納されます。(Emacs 風の挙動。連続した単語削除を一回のペーストでまとめて貼り付けられます)
これまでは日本語の単語分割が認識されず、またクリップボードにも格納されませんでした。
option + ⌦
(option + fn + ⌫)		Ctrl + DeleteKill word right日本語対応
同様に単語単位で右の単語を削除し、クリップボードに格納します。
