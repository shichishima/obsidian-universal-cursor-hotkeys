For everyone — 設定

Obsidian の 設定 → コミュニティプラグイン Universal Cursor Hotkeys を選択 → 上部タブ For everyone を開きます。

Apply all ボタン​

このページにあるすべての設定トグルを ON にします。(Upgrade navigation basics × 8 つ、Upgrade word commands × 4 つ、Behavior options × 5 つ)

ただし、競合可能性があるもの (🔴Used ステータス) はスキップされます。

Upgrade navigation basics (基本操作のアップグレード)​

各キー設定は単純な ON / OFF トグルです。各キー設定の挙動変化の詳細は キーのアップグレード (基本操作のアップグレード) を参照してください。

ON にするとそのキーが対象コマンドのホットキーに追加されます。すでに対象コマンドにホットキーが割り当てられている場合は、それらはそのままに、このキーが追加登録されます。

OFF にするとそのキーの割り当てだけが削除されます。他のホットキー割り当ては変化しません。

各設定行の見方​

ステータストグル意味
(表示なし)OFFキーは標準挙動そのままで変更されていません。アップグレード挙動が割り当て可能な状態です。
(表示なし)ONキーがこのプラグインのアップグレード挙動に割り当てられています。
🔴UsedOFF
(disable)		このキーはすでに別のコマンドで使用されています。このため、このコマンドを追加で割り当てることができません。(ON にすることはできません)
キーチップあるいはステータスをクリックすると Obsidian のホットキー設定画面に遷移するので、そこで割り当て中のコマンドを確認してください。
🔴ConflictONこのキーにはアップグレードコマンドとそれ以外のコマンドの両方が割り当てられていて、現状すでに競合状態です。
キーチップあるいはステータスをクリックしてホットキー設定画面に移動し、競合状態を整理してください。なおトグルスイッチを OFF にすると 🔴Used ステータスに変化し、そのままでは ON にできません。

Behavior options (挙動オプション)​

各種挙動を調整するトグルボタンです。

同じ名称の設定項目は「For everyone」「Vim mode」「macOS (Emacs) style」で連動していて、一方で ON (または OFF) にすると他方でも連動して ON (または OFF) になります。

設定デフォルト説明
Smart home (standard)ONON: Home キーが先頭の Markdown 記法 (リスト、番号付きリスト、チェックボックス、インデント、引用) の手前、本文テキストの先頭に移動します。Windows の Home / macOS の command + ← と同様の挙動です。

OFF: Home キーは Markdown 記法を考慮せず、行の先頭に直接移動します。macOS / Emacs の Ctrl + A と同様の挙動です。
Smart home (advanced)ONON: Smart home (standard) の挙動に加えて、見出し (#)、脚注 ([^1]:)、コールアウトの種類マーカー ([!type]) も追加で考慮します。Smart home (standard) が ON の場合のみ ON にできます。

OFF: 見出し行・脚注・コールアウトを考慮しません。(素の Home と同等に論理行頭に移動します)
Visual line movementONON: 折り返しのある長い行で Home / End を押した際、1 段階目は表示行の先頭 / 末尾に移動します。

OFF: 折り返し行であっても Home / End は表示行を考慮しません。Home は行の先頭 (Smart home 設定により、論理行の先頭または本文テキストの先頭)、End は論理行の末尾に移動します。
Cross-row navigationONテーブル内での Home / End の挙動を調整します。

ON: 左端セルの先頭で Home を押すと、上の行の右端セル末尾に移動します。同様に、右端セル末尾で End を押すと下の行の左端セル先頭に移動します。
行がない場合にはテーブルの外に脱出します。
(← / → の挙動相当です)

OFF: Home / End でテーブル行移動せず、左端セル先頭または右端セル末尾で停止します。
Double-click word selectONマウスのダブルクリックによる単語選択の挙動を調整します。

ON: 辞書ベース単語分割により、マウスダブルクリック時に日本語の単語単位で範囲選択します。
ダブルクリック後にドラッグすると、単語単位で選択範囲が拡張します。

OFF: Obsidian 標準のダブルクリック挙動です。日本語は漢字ひらがなを区別せずひとまとまりで選択されます。
